Upload and display a custom mouse cursor image on selected pages of your WordPress site. A simple way to enhance user experience and add visual flair!

== Description ==

**Cursor Maker** allows you to easily change your website’s default mouse pointer to a custom image-based cursor on specific pages. This plugin is perfect for branding, gamification, portfolios, or any creative site wanting to stand out with unique visual effects.

### 🎨 Features

- Upload your own custom cursor image (.png, .cur, .gif recommended)
- Apply the cursor on **selected pages only**
- Uses WordPress Media Uploader for image selection
- Clean integration with WordPress theme standards
- Lightweight, no front-end JavaScript dependencies

### 🛠 Use Cases

- Add a fun cursor on your landing page
- Showcase your brand identity with a custom pointer
- Provide interactive user experience on specific content
- Great for designers, creatives, or niche stores

== Installation ==

1. Upload the plugin folder `cursor-maker` to the `/wp-content/plugins/` directory.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Go to **Settings > Cursor Maker** in the WordPress dashboard.
4. Upload your custom cursor image.
5. Select the pages where you want the custom cursor to be applied.
6. Save changes and visit the selected pages to see your custom cursor in action!

== Frequently Asked Questions ==

= What image formats are supported? =  
You can use `.png`, `.gif`, or `.cur` files. PNGs with transparency and a size around 32x32px are recommended.

= Will the cursor appear on the entire website? =  
No, the plugin lets you choose which **pages** to display the custom cursor on. It does not affect other parts of the site.

= Can I use different cursors for different pages? =  
Not yet — the current version supports one global custom cursor. If you need per-page cursor settings, that feature is under development.

= Does it work with any theme? =  
Yes, Cursor Maker is built following WordPress coding and theme standards, and should work with any properly coded theme.
